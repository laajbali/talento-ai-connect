# Mobile Application and CV Page Refinements

## Application page
- Keep status filters in one swipeable horizontal row on mobile, preserving the current selected-state styling and default filter.
- Let job titles wrap to two lines, keep status badges aligned, and maintain comfortable action-button tap targets.
- Prevent page overflow and preserve clear spacing above the fixed bottom navigation.

## CV page
- Keep templates in one column on mobile with compact, consistently proportioned previews that fit the viewport.
- Clarify whole-card selection and selected state while retaining “Use this template” as the primary action.
- Reduce excess preview whitespace and preserve the existing desktop/tablet layout and Talento visual system.

## Navigation and verification
- Preserve Home, Jobs, Application, CV, More with the existing icons, destinations, and active state.
- Verify both pages at mobile width for swipe behavior, fit, selection, tap targets, and zero horizontal overflow.
